# 🐍 Python Basics to Advanced
This repository contains Python programs organized topic-wise,
covering Python from basic to advanced concepts along with projects.
It is designed for learning, practice, and revision.

## 🧠 Topics Covered

### Python Basics
- Variables & Data Types
- Operators
- Conditional Statements (if/else)
- Loops (for, while)

### Functions
- User-defined Functions
- Arguments & Return Values
- Lambda Functions

### Data Structures
- Lists
- Tuples
- Sets
- Dictionaries

### Advanced Python
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling
- Modules & Packages

### Projects
- Beginner to intermediate projects
- Real-world problem solving

## 🚀 How to Run

1. Clone the repository:
   git clone https://github.com/ayushhh026/AdvPython.git

2. Navigate to the folder:
   cd AdvPython.git
3. Run any file:
   python filename.py
